平面向量基本概念

2026-08-24T08:30:17.000Z2026-08-26T02:33:42.642ZChina

Hello everybody，我是Cat。今天我们来聊聊平面向量的有关内容。

导语

众所周知，平面向量是高等中学，高等教育学校有关于数学（math）教学的重要篇目。众多几何题目可以运用平面向量快速解题。从而获得高分。

向量的概念

为了方便解释，我们采用表格的形式展现出来，这样就不用浪费太多时间，同时，我们也可以更加直观的了解向量的基本概念。

概念 说明
向量 既有大小又有方向的量。如力、位移、速度。
注意：向量不能比较大小（只能说模的大小）。
向量的表示 几何表示：用有向线段表示，长度表示大小，箭头指向表示方向
注意：电子体，印刷体的向量可以使用粗体字表示如：向量a的手写体为$\vec{a}$，印刷体为a。
字母表示：$\vec{a}$、$\vec{b}$ 或 $\overrightarrow{AB}$（起点A，终点B）。
坐标表示：在平面直角坐标系中 $\vec{a}=(x, y)$。
向量的模 向量的大小（长度），记作 $\lVert\vec{a}\rVert$ 或 $\lVert\overrightarrow{AB}\rVert$。
若 $\vec{a}=(x,y)$，则 $\lVert\vec{a}\rVert=\sqrt{x^2+y^2}$。
零向量 长度为 0 的向量，记作 $\vec{0}$，方向任意。
坐标表示为 $(0,0)$。
单位向量 模为 1 的向量。与非零向量 $\vec{a}$ 方向相同的单位向量为 $\frac{\vec{a}}{\lVert\vec{a}\rVert}$。
相等向量 长度相等且方向相同的向量。
向量与起点的位置无关，可自由平移。
相反向量 长度相等但方向相反的向量。
$\vec{a}$ 的相反向量记作 $-\vec{a}$；$\overrightarrow{AB} = -\overrightarrow{BA}$。
平行向量（共线向量） 方向相同或相反的非零向量。
向量 $\vec{a}$ 与 $\vec{b}$ 平行记作 $\vec{a} \parallel \vec{b}$。
规定：$\vec{0}$ 与任何向量平行。
共面向量 平行于同一个平面的向量。
空间中任意两个向量总是共面的，但三个向量不一定共面。

向量的特殊概念

概念 说明
基向量 坐标轴方向上的单位向量。
平面：$\vec{i}=(1,0)$，$\vec{j}=(0,1)$。
空间：$\vec{i}=(1,0,0)$，$\vec{j}=(0,1,0)$，$\vec{k}=(0,0,1)$。
法向量 垂直于平面或直线的非零向量。
平面的法向量垂直于平面内的所有向量。
自由向量 与起点无关，可任意平移的向量。
一般讨论的向量多属于自由向量。
位置向量 以坐标原点为起点，指向某点的向量。
点 $P(x,y)$ 的位置向量为 $\overrightarrow{OP}=(x,y)$。
